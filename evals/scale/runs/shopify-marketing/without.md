# Promo « Automne » −15 % sur Shopify — Plan d'exécution complet

## 1. Objectifs et cadre

| Élément | Valeur |
|---|---|
| Offre | −15 % sur la collection « Automne » (pas de cumul avec d'autres codes) |
| Durée | 10 jours : du **lundi 19 octobre** au **dimanche 28 octobre 2026**, inclus |
| Objectif principal | Décoller les ventes : +30 à 40 % de chiffre d'affaires sur la période vs 10 jours équivalents hors promo |
| Objectif secondaire | Remonter les taux de conversion et réactiver une liste d'emails existante |
| Garde-fou | Marginalité : −15 % reste absorbable si votre marge brute dépasse 50 % ; au-delà, envisagez −10 % ou un produit « cadeau » à la place |

**Projection simple pour cadrer** : si la collection « Automne » fait 5 000 € de CA sur 10 jours en rythme normal, attendez-vous à 6 500–7 000 € en promo, soit un CA supérieur d'environ 1 500–2 000 € malgré les 15 % cédés. C'est ce qu'on vise : le volume doit compenser la remise.

## 2. Mise en place technique Shopify (30–60 min, à faire J-2, soit le samedi 17 octobre)

**Étape 1 — Créer le code promo**
1. Shopify Admin → **Boutique en ligne → Codes promotionnels → Créer un code de promotion**.
2. Type : **Réduction** → 15 %, appliqué à **des produits spécifiques** → sélectionner la collection « Automne » (ou les produits de la collection).
3. Code : `AUTUMNE15` (simple, mémorisable, lisible à l'oral).
4. Dates : 19/10/2026 00:00 → 28/10/2026 23:59.
5. Limites : aucune limite de commandes (promo publique) ; vérifier qu'aucun cumul avec d'autres codes n'est actif.

**Étape 2 — Annoncer la promo en vitrine**
- **Bannière de site** (Shopify Admin → Boutique en ligne → Personnaliser → Bannière d'annonce) : « Promo Automne : −15 % avec le code AUTUMNE15 jusqu'au 28 octobre ».
- **Page de la collection** : ajouter un texte en haut de page « Automne −15 % ce mois-ci — code AUTUMNE15 » via un bloc de texte ou un app de bannière.
- **Fiche produit** : optionnel mais efficace — un snippet « code AUTUMNE15 » sur les fiches de la collection via un app type « Klevin Shop » ou un simple bloc image/texte.

**Étape 3 — Préparer les emails (Shopify Email ou votre ESP)**
Rédiger **dès J-2** les 3 emails du parcours (contenus dans la section 5), pour éviter de bricoler le samedi soir.

**Tests obligatoires avant le lancement** :
- Commander à 1 € avec le code sur un produit de la collection → vérifier que la remise s'applique.
- Commander sans le code → vérifier qu'aucune remise.
- Vérifier l'affichage de la bannière sur mobile et desktop.
- Vérifier que le code ne s'applique pas aux produits hors collection.

## 4. Canaux d'activation

**Emails (cœur du dispositif — c'est là que 60 à 70 % des ventes promo se font)**
1. *J-1, teasing* — Objet : « Demain, la collection Automne passe à −15 % ». Corps : 3 produits phares, code `AUTUMNE15` visible, urgence douce (« dès demain 00h »).
2. *J1, lancement* — Objet : « C'est parti : −15 % sur toute la collection Automne ». Corps : bannière, lien direct vers la collection, code en gros, CTA unique.
3. *J5, relance* — Objet : « Encore 5 jours pour la promo Automne ». Corps : rappel du code + 1 avis client ou produit « coup de cœur ».
4. *J10, deadline* — Objet : « Dernier jour : −15 % Automne s'arrête ce soir ». Corps : 300 mots max, urgence franche.

**Réseaux sociaux / publicités (selon votre budget)**
- Organique (gratuit) : 3 posts minimum — lancement, mi-promo, « dernières 48 h ». Format : visuel de la collection + code en légende.
- Payant (optionnel, recommandé si budget ≥ 300 €) : campagne Meta (Facebook/Instagram) à 30–50 €/jour sur les jours 1-4, audience = retargeting 30 jours (visiteurs du site + prospects panier abandonné) + lookalike de vos acheteurs. Objectif : trafic vers la page collection. Stoppez la diffusion le J9.

**Panier abandonné**
- Vérifier que la séquence d'emails panier abandonné est active ; elle doit mentionner automatiquement la remise si le code est appliqué, ou au minimum inciter à appliquer `AUTUMNE15`.

## 6. Suivi : KPI à regarder chaque matin (10 min)

| KPI | Où le voir | Repère de succès |
|---|---|---|
| Taux de conversion site | Shopify Admin → Dashboard | ≥ 1,5× le taux habituel (la promo pousse à acheter) |
| Panier moyen | Dashboard | Ne doit pas chuter de plus de 15 % (sinon la promo s'applique à des paniers trop remplis) |
| Nombre de commandes | Dashboard | +30 % dès J3 par rapport à la veille de promo |
| Taux d'ouverture email | Votre ESP | ≥ 30 % (si < 20 % : sujet trop mou, tester un autre objet) |
| Stock des best-sellers | Inventaire | Alerte si < 10 unités restantes |

**Bilan J+7 (semaine du 29/10)** : CA promo vs prévision, marge nette promo, nouvelles clientes vs clientes existantes, coût d'acquisition par canal. C'est ce bilan qui décidera de la promo de Noël.

## 7. Risques et pièges à éviter

1. **Rupture de stock sur les best-sellers** : vérifier aujourd'hui que les 5 produits les plus vendus de la collection ont un stock ≥ 3× leur vente moyenne 10 jours.
2. **Clientèle « en attente » déçue** : si vous faites souvent des promos, une partie des ventes normales va se reporter sur la promo. C'est inévitable — le test, c'est de comparer le CA **net** (après remise) à la période normale.
3. **Code non cumulatif** : indiquer clairement en bas de bannière « non cumulable avec d'autres offres » pour éviter les litiges.
4. **Oublier le démontage** : le 29/10, retirer la bannière et ne pas laisser de vieux visuel « promo » en vitrine (crédibilité).
5. **Pas de promotion de Noël trop proche** : si Noël démarre avant fin novembre, ajoutez une ligne « et ce n'est qu'un avant-goût » pour ne pas tuer l'attente de Noël.
