# Message de réassort — Client Dupont

**Contexte** : le client Dupont commande environ tous les 30 jours. Sa dernière commande date de 45 jours, soit environ 15 jours de retard sur son rythme habituel. C'est le moment idéal pour prendre contact proactivement.

---

## E-mail proposé

**Objet :** Votre réassort hebdomadaire est sans doute proche

Bonjour [prénom] Dupont,

En parcourant notre historique, j'ai constaté que votre dernière commande date de mi-juin. D'après votre rythme habituel (~30 jours), votre réassort devrait normalement avoir lieu cette semaine.

Avant que vous ne soyez contraint par une rupture, je vous propose de préparer votre prochaine commande dès maintenant :

- **Réassort standard** : je vous renvoie votre dernière commande en préremplie, à modifier si besoin ;
- **Ajustement de volumes** : si vos besoins ont évolué, dites-le-moi et j'adapte les quantités ;
- **Livraison planifiée** : à réception de votre bon, nous préparons et expédions sous [délai standard] jours.

Si vous préférez, je peux passer vous voir / vous appeler [proposer 2 créneaux] pour finaliser ensemble.

Dans l'attente de votre retour, je reste à votre disposition pour toute question.

Cordialement,
[Votre nom]
[Votre fonction] — [Société]
[Téléphone] — [E-mail]

---

## Recommandations pour l'envoi

1. **Envoi aujourd'hui** : plus le retard s'allonge, plus le risque d'aller voir un concurrent augmente.
2. **Personnaliser** : remplacer les champs entre crochets ; ajouter un produit récent ou une promotion si pertinent.
3. **Suivi** : si pas de réponse sous 3 jours, passer un appel court (l'e-mail seul peut ne pas suffire après 45 jours de silence).
4. **Sécuriser le cycle** : à l'occasion, proposer un réassort automatique ou un contrat d'approvisionnement mensuel — cela transforme un rappel ponctuel en relation récurrente.
5. **Suivre dans le CRM** : noter le contact du 15/10 ; si la commande arrive, recalculer le cycle réel pour affiner la date du prochain relance.

## Point de vigilance

45 jours de silence peut aussi signaler un problème (insatisfaction, besoin disparu, changement de fournisseur). Le ton du message doit rester chaleureux et orienté service, jamais de relance agressive : l'objectif est d'ouvrir le dialogue, pas de réclamer.
